# Удаление фона с изображений

Простая программа, которая убирает фон с картинок и сохраняет их в PNG с прозрачным фоном.  
Работает на Windows, не требует интернета (кроме первого запуска, если выбрана AI‑модель).

---

## Что нужно для работы

- **Windows 7 / 8 / 10 / 11**
- **Python 3.8 или новее** — скачать можно с [python.org](https://www.python.org/downloads/).
  При установке обязательно поставь галочку **«Add Python to PATH»**.

Всё остальное (`Pillow`, при необходимости `rembg`) файл `run.bat` установит сам при первом запуске.

---

## Как пользоваться — по шагам

1. **Создай папку** для программы, например `C:\RemoveBG`.
2. Положи в неё три файла:
   - `remove.py`
   - `run.bat`
3. **Создай папку `in`** рядом с ними и положи туда картинки, у которых хочешь убрать фон.  
   Поддерживаются форматы: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`, `.tiff`, `.tif`.
4. **Двойной клик по `run.bat`.** Откроется чёрное окно — не закрывай его, дождись надписи «Готово!».
5. Готовые картинки с прозрачным фоном появятся в папке **`out`**.

Итоговая структура должна выглядеть так:

```
RemoveBG\
├─ remove.py
├─ run.bat
├─ in\        ← сюда кладёшь исходные картинки
└─ out\       ← здесь появятся результаты
```

## Два режима работы

Режим задаётся в файле `remove.py`, строка:

```python
MODE = "pillow"   # или "rembg"
```

### `pillow` — простой (по умолчанию)

Убирает **белый и светло-серый** фон. Работает мгновенно, ничего не скачивает.

- Подходит для: логотипов, схем, картинок с однотонным светлым фоном.
- Не подходит для: фотографий и сложных фонов.

Если фон не чисто белый — можно снизить порог. В `remove.py` есть параметр:

```python
THRESHOLD = 220
```

- `240` — только почти белый фон.
- `220` — белый + светло‑серый.
- `200` — захватывает ещё более тёмный фон (но может «съесть» части картинки).

### `rembg` — AI‑режим (для фотографий)

Убирает фон **с любой фотографии** — людей, предметов, сложных сцен.

- Первый запуск скачает модель (~170 МБ) — нужен интернет, займёт пару минут.
- Работает медленнее (несколько секунд на картинку).
- Не подходит для старых слабых ПК и Windows 7.

**Как включить:** открой `remove.py` в Блокноте, найди строку `MODE = "pillow"` и замени на:

```python
MODE = "rembg"
```

Сохрани файл и запусти `run.bat` — библиотека `rembg` установится автоматически.

## Возможные проблемы

| Симптом | Что делать |
|---|---|
| Окно мелькает и закрывается | Запусти через `run.bat` (он оставляет окно открытым). |
| «Python не найден в PATH» | Переустанови Python с галочкой **«Add Python to PATH»**. |
| «Папка 'in' не найдена» | Создай папку `in` рядом с `run.bat`. |
| Русские буквы — «кракозябры» | Сохрани `run.bat` в Блокноте в кодировке **UTF‑8** (уже сделано, если файл не редактировался). |
| Фон остался на месте | Уменьши `THRESHOLD` (например, до 200) или переключись на режим `rembg`. |
| Части картинки стали прозрачными | Увеличь `THRESHOLD` (например, до 240). |
| В режиме `rembg` ошибка установки | Установи Microsoft Visual C++ Redistributable и повтори запуск. |

## Частые вопросы

**Куда сохраняются результаты?**  
В папку `out`. Имена совпадают с исходными, но расширение всегда `.png`. Если файл с таким именем уже существует — он **перезапишется**.

**Исходные картинки меняются?**  
Нет, папка `in` только читается.

**Можно обрабатывать сразу много файлов?**  
Да, все картинки из `in` обрабатываются за один запуск.

**Можно запускать из другого места?**  
Да, `run.bat` всегда работает с папкой, где он лежит, независимо от того, откуда его запустили.
